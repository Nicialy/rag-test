# Оценка влияния архитектур RAG на консистентность перевода имён собственных в художественных текстах


## Методология исследования
### Архитектуры RAG
Для исследования использовалась базовая модель mistral-large-latest. Были протестированы 4 конфигурации (Агентов):

- Agent 0 (Baseline): Первичный перевод без использования внешнего контекста. 

- Agent 1 (VectorRAG): Использование чанков конеткстного перевода похожих предложений из предыдущих глав.

- Agent 2 (GraphRAG): Использование графового индекса. Извлекаются сущности (персонажи) их атрибут (пол) и перевод. Информация подается в контекст при генерации.

- Agent 3 (HybridRAG): Комбинация GraphRAG и VectorRAG. Сочетает структурированные связи сущностей с  поиском по векторной базе.

- Agent 4 (RAG-Fusion + GraphRAG): Использование многопоточных запросов (query expansion) и переранжирования для повышения точности извлечения из графа.

### Оценка стабильности перевода имен собственных
1. Для каждой главы оригинального текста (Src) и машинного перевода (Mt) были извлечены именованные леммы для имен.
2. С использованием модели sentence-transformers/LaBSE (которая понимает связь между английскими и русскими словами) было рассчитано косинусное сходство для каждого уникального имени на английском и его возможных переводов на русский.
3. Для каждого имени на английском был выбран наиболее частый перевод на русский (эталон).
4. Оценивалась стабильность перевода: для каждого эталонного имени проверялось, совпадают ли переводы в разных главах(None - не учитываем).

## Классические метрики
Данные метрики подтверждают, что использование RAG не портит общую структуру и читаемость текста, но они абсолютно нечувствительны к консистентности художественного мира.
## Стабильность перевода имен
В рамках Таблицы 2 и 3 мы видим приимущество использование RAG архитектур над простой модели в рамках точности перевода Имён.
Довольно старнное наблюдение что Базовый VectorRAG привосходит GraphRAG, ибо в одном случаи мы храним чанки оригинал - перевод (по нескольким предложениям), а в другом конкретно персонажей и их перевод с полом, я бы скорее списал данную не значительную особенность на определение NER от LaBSE.

### Выводы и направления для улучшения
1. Зависимость от точности модели LaBSE: Метрика напрямую зависит от качества эмбеддингов. Возможно улучшение за счет подбора более точной модели или ее улучшение
2. Для более точной оценки стабильности перевода имен собственных рекомендуется использовать книги с большим количеством глав, где герои упоминаются в каждой главе.
