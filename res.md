План Оценки (Ожидаемые Результаты)
Для корректной оценки метрик качества перевода необходимо определить:

Набор тестов (Test Set): Оригинальный текст, эталонный перевод (Ground Truth) и целевой текст (наш перевод).

Метрики:

BLUE / SacreBLEU: Общая мера сходства с эталонным переводом.

ROUGE: Оценка совпадения n-грамм и длинных последовательностей.

Gender Error Rate (Специальная метрика): Процент случаев, когда род персонажей передан неверно (например, "он сказал" вместо "она сказала"). Это будет ключевой метрикой для сравнения с Baseline.

Сравнение результатов по этим метрикам позволит выбрать лучший метод для финального внедрения.
